# Getting Started

## Install / Update

1. Download `AxoTales-<version>.jar`.
2. Copy it to your Hytale mods folder: `...\Hytale\UserData\Mods`
3. Remove older `AxoTales-*.jar` files (keep only one version).
4. Start/restart the game/server.

If an old jar won't delete, the game/world still has it open. Quit first, then delete it.

## Configuration file

After first run, Axo Tales creates `server-config.json` in the mod's data folder.

Use it to tune:
- mana costs and cooldowns
- worldgen (Arcane Matter ore + Arcane Crystals)
- Kudu Rune Knight spawns and drops
- Ancient Sword ability settings

## Crafting benches

- **Arcane Workbench**: Axo Tales gear + spellbooks (Axo Tales tab)
- **Alchemybench**: Axo Tales potions
