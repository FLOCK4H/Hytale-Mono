## Quick install path

1. Use **AxoTales 0.1.3+**, built for **Hytale 0.7.7** and **Java 25**.
2. Keep one current JAR in the server's mods folder or `%APPDATA%/Hytale/UserData/Mods`.
3. Close the game or server before replacing a locked JAR, then restart. Preserve your saves and configuration.

<div class="guide-note"><p><strong>Server values can vary.</strong> The numbers here use the mod's default settings. Server owners can change spell costs, encounter rates and world generation.</p></div>
