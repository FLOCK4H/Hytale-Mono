# Axo Tales Guidebook

Axo Tales is a magic-focused Hytale mod (plugin + asset pack). This guidebook documents:

- items and what they do
- crafting and how to obtain items
- blocks/ores and world generation
- Kudu encounters (NPCs)
- server configuration (`server-config.json`)
