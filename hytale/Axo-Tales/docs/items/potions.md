# Potions

All Axo Tales potions require **Axo's Empty Potion Bottle**.

## Axo's Empty Potion Bottle

**What it does**
- Throwable empty bottle used as the base for brewing Axo Tales potions.

**Crafting (Alchemybench -> Alchemy_Potions_Misc)**
- Empty Potion Bottle (`Potion_Empty`) x1
- Arcane Crystal Shard (`Ingredient_Crystal_Arcane`) x1

## Swift Potion

- Effect: movement speed buff (60 seconds).
- Crafting (Alchemybench -> Alchemy_Potions):
  - Axo's Empty Potion Bottle x1
  - Arcane Crystal Shards x2
  - Cyan Hibiscus (`Plant_Flower_Common_Cyan2`) x2

## Strength Potion

- Effect: doubles outgoing damage (60 seconds).
- Crafting (Alchemybench -> Alchemy_Potions):
  - Axo's Empty Potion Bottle x1
  - Arcane Crystal Shards x2
  - Adamantite Ingots (`Ingredient_Bar_Adamantite`) x10

## Rabbit Potion

- Effect: jump height buff (60 seconds).
- Crafting (Alchemybench -> Alchemy_Potions_Misc):
  - Axo's Empty Potion Bottle x1
  - Arcane Crystal Shards x2
  - Dark Feather (`Ingredient_Feathers_Dark`) x1

## Invisibility Potion

- Effect: hides you from other players (60 seconds).
- Crafting (Alchemybench -> Alchemy_Potions_Misc):
  - Axo's Empty Potion Bottle x1
  - Arcane Crystal Shards x2
  - Azure Kelp (`Plant_Crop_Mana3`) x1

## Curse Potion

- Type: throwable splash vial.
- Effect: explodes in cursed damage on splash.
- Crafting (Alchemybench -> Alchemy_Bombs):
  - Axo's Empty Potion Bottle x1
  - Arcane Crystal Shards x2
  - Essence of Fire (`Ingredient_Fire_Essence`) x5
